# 次数1・2の非可換del Pezzo n-fold

**2026-11-20（JST） / v0.12 — 現行研究一式**

最初に [研究方針](00_research_plan.md) を読む。対象は一般の `n ≥ 2`、次数 `d=1,2`。構造対象 **Oだけを標識**し、射には全てのO保存完全Abel同値を採用する。GitHub mainが正本である。

## 中心となる到達点

**両次数・全n≥2で、滑らかな可換零切断全体を含む一つの有限型開近傍に、全O保存完全Abel同値による整なDeligne–MumfordスタックUを構成した。** 同じ有限中心商族が全滑らかな可換模型とその全framed Abel Artin変形を実現する。次数1、および次数2のn=2ではUは滑らか。次数2のn≥3では、非smoothな点は可換部分に一致する。非零方向の非空開部分では有限étale慣性と滑らかな粗モジュライ代数空間を得る。全モジュライM内でのUの開性、全対象の被覆と全成分数は未証明である。

- **次数1：** 方向空間は `E* ≅ A^n`。ambientの明示的開条件は `g₁=(1+A₄(D))(5+A₄(D))≠0`。4次までの座標不変な中心jetを全係数の厳密計算で与え、`P(E*)` 上の `H¹(Sym⁶K(m))=0 (m≥5)` により全高次へ持ち上げ、有限線型方程式で代数化する。
- **次数2：** 方向空間は `Gr(2,n+1)` のPlückerアフィン錐。ambientの明示的開条件は `g₂=det(1+4T)≠0`。中央多項式係数上の形式中心と `H¹(Sym⁴K(m))=0 (m≥0)` から、錐の頂点を含めて中心元を構成する。全四次係数を許すが、退化ファイバーの中心全体が一定階数とは主張しない。
- **全Artin普遍性：** 滑らかな可換点で係数空間の横断sliceを選ぶと、この有限中心商のArtin基底変更が全framed変形を分類する。DDLの比較、初交換子、既存の全完備局所環を使う。後述の有限基底上の圏論的結果は独立に証明しており、形式的完全性から自動的に推論していない。

中心元のためには、ambientの明示条件に加えて零切断上で1となる有限な追加分母を選ぶ。その存在を証明した段階であり、最小行列式や中心元の全方向に共通する閉じた公式は未計算である。次数1の4次jetを有限パラメータでの厳密な中心公式とは扱わない。

## 形式モジュライと圏論的結果

framed形式環は、次数1では `b(n,1)+n` 変数の冪級数環、次数2では `b(n,2)` 次元の形式円板とPlücker錐の頂点完備化の積である。各可換点の形式分枝は一つ。次数2・`n≥3` は特異で、二次障害は `Q∧Q`。通常の多様体の変形方向では相殺できない。

HH¹(X)=0によってframed自己同値は消え、枠を忘れた形式群oidは `[Spf R_X/Aut(X)]` となる。一般点での被覆対合の符号粗商は両次数とも特異であり、正規Cohen–Macaulay整域である。粗商のArtin点と変形同型類は区別する。

全Abel Artin変形について、通常の重み付き中心超曲面表示、飽和性・有向ACM・全正周期の豊富性・compact生成・smooth proper性と、perfect圏のSerre公式 `S=(−(n−1))[n]` を証明した。Artin近傍の全O保存同値は、通常のgraded環同型を次数スカラーで割ったものとして認識できる。別に、条件を明示した反標準section復元と、中心一次変数による任意指数Veronese持上げを保持する。

## 全方向族の有限基底上の相対幾何

活性最高次曲線の退化を含めて相対THCRを構成した。次数1は三次根による尺度変更を取り除いた階数2被覆で、節点・尖点を含む整なGorenstein種数1曲線を使う。次数2は有限平坦二重被覆 `E→P¹` を使い、可約曲線と非被約な二重P¹も扱う。後者のnilradical `O(−2)` を含めて正次数コホモロジーの消滅を確認する。

方向イデアルを `J=(a₁,…,aₛ)` とすると、任意Noether基底Rに対する `R→R̂_J×∏R[aᵢ⁻¹]` は忠実平坦である。完成側のNoether性は次数別有限性とKrull交叉から、頂点外では相対THCRから得る。これにより、同じ全方向ambient A、中心商B、および `Aᵒᵖ⊗A`・`Bᵒᵖ⊗B` は任意Noether基底変更後も左右Noetherとなる。方向解消を平坦と仮定しない。

有限な次数零Hom複体から相対projective対角解消を構成し、ambientの無捩れな相対CY同型を得た。中心商のtailsは飽和性・有向ACM・χ・全シフトの豊富性とSerre公式 `S=(−(n−1))[n]` を持つ。compact生成窓は次数1で `⊕_{j=0}^{n+4}O(j)`、次数2で `⊕_{j=0}^{n+2}O(j)`。対角の有限部分解消とHH¹(X)=0を使い、滑らかな可換零切断の有限開近傍でsmooth proper性と反標準豊富性を得る。非正則な基底上の全Db(coh)をcompact圏と同一視しない。

分離型の明示的中心公式・普遍中心、一般楕円型の具体的な曲線と有限中心行列も、有効な再現資産として保持する。一方向族のPoisson Kodaira–Spencer像は高々1次元なので、それだけでは全変形を被覆しない。全方向族はこの不足を解消している。

## 有限型族の全O保存同値

反標準環 `R=B^(n−1)` に対し、全同値層は `Eq^O(QGr B₁,QGr B₂) ≅ Isom_gr(R₁,R₂)/G_m` となる。これは構成したsmooth proper開集合Vの `V×V` 上でアフィンかつ有限表示で、任意の許された基底変更・合成と両立する。反標準軌道上の相対Serre比較と豊富列復元を用いるので、基本シフトを保つ同値だけに射を制限していない。

Veronese環の有限表示は右Noether性とaugmentationの有限syzygyから得る。次数1の同型行列と逆行列がスカラー作用について重み±1を持ち、行列積の恒等式が座標環の強Z次数付けを与えるため、スカラー商もアフィンとなる。全同型方程式の最小の生成・関係次数は未計算である。

零切断を保ってVを縮めると、同値スキームはさらにquasi-finiteかつunramifiedとなり、各幾何学的点の全O保存自己同値群は有限となる。相対Hochschild複体についても、任意の非平坦affine係数変更後に `HH^{<0}=0, HH⁰=R, HH¹=0` が成立する開近傍を得た。存在する対角bimoduleのArtin持上げの剛性は、そこにある実際の非可換点にも適用できる。

非零方向上では、中央一次Casimir束Kに対してBがSym K上普遍的に平坦である。`n≥3` では `q=n−1` の一つの交換子行列に最大階数条件を課すと、普遍的に `Z(B)_q=Sym^q K` となる非空稠密開Uを得る。任意の滑らかな可換係数fと非零方向ξから出る直線 `(f,hξ)` はUと非空な非零部分で交わる。U上ではVeronese同型の持上げがμ_(n−1)-torsorであり、`Eq^O ≅ Isom_gr(B₁,B₂)/G_m` となる。`n=2` は反標準環がBなので、V全体でこの認識が成立する。

さらに方向を射影化したproperな解消上で交換子を方向パラメータで割り、その階数が落ちる閉集合の像を除く。これにより零切断Z全体を含む一つの開近傍V°で、V°\Zが低次数中心開Uに入る。後述のH→Eの開性と可換零切断の保存を合わせると、**V°全体で通常Bによる全同値認識**が成立する。冪零方向を持つ基底や零方向への特殊化も含む。

## 可換零切断を含む全同値の有限型モジュライ

全係数表示の座標自由度を `g₁=n²`, `g₂=(n+1)²` とする。可換零切断の任意の矢α:x→yで、完成局所環は `R_X[[u₁,…,u_g,v₁,…,v_g]]`、sourceの完成は `R_X[[u₁,…,u_g]]` の包含である。全Artin比較によりsource・targetは相対次元gで滑らかになる。可換零切断は全同値でschemeとして保存される。

非零方向のgraded同型は、低次数の完全対称化と交換子関係から重み付き線型になる。座標変換を取り除くと、残るパラメータ差は次数1でSym⁶K、次数2でSym⁴Kの中央係数だけである。この係数方向における中心元Ωの微分JΩは、方向解消の例外因子上で恒等となる。properな悪条件像を除いてJΩを可逆にし、小Artin拡大の中心差Δを `ξ=JΩ⁻¹Δ` で補正する。中央係数写像の大域的単射性は要求しない。

従って零切断Z全体を含む不変な開Wで、**全ての矢を保った**群oidE_W⇒Wのsource・targetが相対次元gで滑らかになる。`U=[W/E_W]` は有限型で整なDMスタックで、局所Noether fppf site上では、Wの族にfppf局所的に同値な対象と、その間の全O保存同値によるfullな部分問題である。全可換模型とその全Artin変形を含む。次数2・n≥3での非smooth locusは、点集合および被約閉部分として可換locusに一致し、Jacobianイデアルによる構造の一致は主張しない。

非零方向の非空な対象開へ制限した商NはUの開部分スタックで、滑らかかつ整である。さらに慣性を有限étaleにすれば粗空間Mも滑らかな整な有限型代数空間となる。次元は `dim U=dim N=dim M=b(n,1)+n` または `b(n,2)+2n−1`。n=2,3,4でそれぞれ次数1は10,37,107、次数2は9,24,52である。分離性と一般安定化群の同定は未証明。

各可換点Xでは、Γ=Aut(X)不変な実際の有限型affine slice Tを取り、`[T/Γ]→U` をrepresentable étaleにできる。可換点の残余gerbe上で同型となり、既存の形式商 `[Spf R_X/Γ]` と両立する。全Uが一つの有限群商であるとは主張しない。

有限型群oidの商はlimit preservingで、可換特殊ファイバーを持つ形式対象は完備Noether局所基底上の実際の有限族として実現できる。任意M(R)の対象に対するformal GAGAや、Uの全M内での開性を意味しない。

## 残る核心と確実性

**次の核心は、構成したDM部分問題Uの全モジュライM内での開性・被覆範囲である。** 一般nc点の全Abel変形に対するKodaira–Spencer像・障害と、versalityの開性を調べる。また零切断を含む範囲の慣性の有限性・粗空間・分離性、一般安定化群、得た近傍の外の中心増大層と追加同値、可換locusに接しない成分を調べる。全Artin普遍性だけでは有限型表示へ移れない一般群oidの反例を保持し、本族では中心Jacobianによる追加の持上げでその障害を解消した。追加開条件の最小明示式と全成分数は残る。

原稿に証明を記述し、主要部分を独立に点検した研究稿である。有限計算の証明書は実行しているが、形式証明器による検証と包括的な優先権調査は未了。各定理の仮定・依存と確認範囲は方針・文献・再現手順に記載する。
