# 次数1・2の非可換del Pezzo n-fold

**2026-11-20（JST） / v0.15 — 現行研究一式**

最初に [研究方針](00_research_plan.md) を読む。対象は一般の `n ≥ 2`、次数 `d=1,2`。構造対象 **Oだけを標識**し、射には全てのO保存完全Abel同値を採用する。GitHub mainが正本である。

## 中心となる到達点

**両次数・全n≥2で、滑らかな可換模型を全て含む、全モジュライMの整な有限型DM開部分Uを構成した。PoissonモジュライPへの表現可能でstabilizer preservingなétale射Θを持ち、次数2ではその一般次数が全n≥2で4である。** 全O保存完全Abel同値で割っても一般の四つの逆像は異なる。Θは開埋込みでなく、有理切断を持たない。Uは有限対角を持ち、粗空間M^ncは正規Cohen–Macaulayな準アフィンスキームである。全幾何学的点のframed Abel Artin変形は同じ有限中心商族が実現する。可換モジュライDへのshadow射は平坦全射で、相対次元は次数1でn、次数2で2n−1。次数1の全比較の一般次数、全対象の被覆、全成分数は未決定である。

- **次数1：** 方向空間は `E* ≅ A^n`。ambientの明示的開条件は `g₁=(1+A₄(D))(5+A₄(D))≠0`。4次までの座標不変な中心jetを全係数の厳密計算で与え、`P(E*)` 上の `H¹(Sym⁶K(m))=0 (m≥5)` により全高次へ持ち上げ、有限線型方程式で代数化する。
- **次数2：** 方向空間は `Gr(2,n+1)` のPlückerアフィン錐。ambientの明示的開条件は `g₂=det(1+4T)≠0`。中央多項式係数上の形式中心と `H¹(Sym⁴K(m))=0 (m≥0)` から、錐の頂点を含めて中心元を構成する。全四次係数を許すが、退化ファイバーの中心全体が一定階数とは主張しない。
- **全点でのArtin普遍性：** 可換点ではDDLの比較、初交換子と全完備局所環を使う。非可換点ではAbel Hochschildと有限窓dg模型を比較し、HH²の上半連続性と全同値からの接空間単射を使う。次数2・n≥3では、二次Plücker障害の微分をHochschildの第一Bocksteinに同定し、方向解消とproperな悪条件像の除去により全点のversalityを一様に得る。任意の剰余体も扱う。

中心元のためには、ambientの明示条件に加えて零切断上で1となる有限な追加分母を選ぶ。その存在を証明した段階であり、最小行列式や中心元の全方向に共通する閉じた公式は未計算である。次数1の4次jetを有限パラメータでの厳密な中心公式とは扱わない。

## 形式モジュライと圏論的結果

framed形式環は、次数1では `b(n,1)+n` 変数の冪級数環、次数2では `b(n,2)` 次元の形式円板とPlücker錐の頂点完備化の積である。各可換点の形式分枝は一つ。次数2・`n≥3` は特異で、二次障害は `Q∧Q`。通常の多様体の変形方向では相殺できない。

HH¹(X)=0によってframed自己同値は消え、枠を忘れた形式群oidは `[Spf R_X/Aut(X)]` となる。一般点での被覆対合の符号粗商は両次数とも特異であり、正規Cohen–Macaulay整域である。粗商のArtin点と変形同型類は区別する。

全Abel Artin変形について、通常の重み付き中心超曲面表示、飽和性・有向ACM・全正周期の豊富性・compact生成・smooth proper性と、perfect圏のSerre公式 `S=(−(n−1))[n]` を証明した。Artin近傍の全O保存同値は、通常のgraded環同型を次数スカラーで割ったものとして認識できる。別に、条件を明示した反標準section復元と、中心一次変数による任意指数Veronese持上げを保持する。

## 全方向族の有限基底上の相対幾何

活性最高次曲線の退化を含めて相対THCRを構成した。次数1は三次根による尺度変更を取り除いた階数2被覆で、節点・尖点を含む整なGorenstein種数1曲線を使う。次数2は有限平坦二重被覆 `E→P¹` を使い、可約曲線と非被約な二重P¹も扱う。後者のnilradical `O(−2)` を含めて正次数コホモロジーの消滅を確認する。

方向イデアルを `J=(a₁,…,aₛ)` とすると、任意Noether基底Rに対する `R→R̂_J×∏R[aᵢ⁻¹]` は忠実平坦である。完成側のNoether性は次数別有限性とKrull交叉から、頂点外では相対THCRから得る。これにより、同じ全方向ambient A、中心商B、および `Aᵒᵖ⊗A`・`Bᵒᵖ⊗B` は任意Noether基底変更後も左右Noetherとなる。方向解消を平坦と仮定しない。

有限な次数零Hom複体から相対projective対角解消を構成し、ambientの無捩れな相対CY同型を得た。中心商のtailsは飽和性・有向ACM・χ・全シフトの豊富性とSerre公式 `S=(−(n−1))[n]` を持つ。compact生成窓は次数1で `⊕_{j=0}^{n+4}O(j)`、次数2で `⊕_{j=0}^{n+2}O(j)`。対角の有限部分解消とHH¹(X)=0を使い、滑らかな可換零切断の有限開近傍でsmooth proper性と反標準豊富性を得る。非正則な基底上の全Db(coh)をcompact圏と同一視しない。

分離型の明示的中心公式・普遍中心、一般楕円型の具体的な曲線と有限中心行列も、有効な再現資産として保持する。一方向族のPoisson Kodaira–Spencer像は高々1次元なので、それだけでは全変形を被覆しない。全方向族はこの不足を解消している。

## 有限型族の全O保存同値

反標準環 `R=B^(n−1)` に対し、全同値層は `Eq^O(QGr B₁,QGr B₂) ≅ Isom_gr(R₁,R₂)/G_m` となる。これは構成したsmooth proper開集合Vの `V×V` 上でアフィンかつ有限表示で、任意の許された基底変更・合成と両立する。反標準軌道上の相対Serre比較と豊富列復元を用いるので、基本シフトを保つ同値だけに射を制限していない。

Veronese環の有限表示は右Noether性とaugmentationの有限syzygyから得る。次数1の同型行列と逆行列がスカラー作用について重み±1を持ち、行列積の恒等式が座標環の強Z次数付けを与えるため、スカラー商もアフィンとなる。全同型方程式の最小の生成・関係次数は未計算である。

零切断を保った開近傍では、同値スキームはquasi-finiteかつunramifiedであり、相対Hochschild複体について任意の非平坦affine係数変更後にも `HH^{<0}=0, HH⁰=R, HH¹=0` が成立する。さらに全同値の重み付き線型性を零切断へ延長し、対称化した中心方程式の古典Isomへの閉埋込みを構成すると、同値スキームの `W×W` への射は有限となる。

非零方向上では、中央一次Casimir束Kに対してBがSym K上普遍的に平坦である。`n≥3` では `q=n−1` の一つの交換子行列に最大階数条件を課すと、普遍的に `Z(B)_q=Sym^q K` となる非空稠密開U_lowを得る。任意の滑らかな可換係数fと非零方向ξから出る直線 `(f,hξ)` はU_lowと非空な非零部分で交わる。U_low上ではVeronese同型の持上げがμ_(n−1)-torsorであり、`Eq^O ≅ Isom_gr(B₁,B₂)/G_m` となる。`n=2` は反標準環がBなので、V全体でこの認識が成立する。

さらに方向を射影化したproperな解消上で交換子を方向パラメータで割り、その階数が落ちる閉集合の像を除く。これにより零切断Z全体を含む一つの開近傍V°で、V°\Zが低次数中心開U_lowに入る。基本シフトを保つ矢の全同値層への開埋込みH→Eと、可換零切断の保存を合わせると、**V°全体で通常Bによる全同値認識**が成立する。冪零方向を持つ基底や零方向への特殊化も含む。

## 可換零切断を含む全同値の有限型モジュライ

全係数表示の座標自由度を `g₁=n²`, `g₂=(n+1)²` とする。可換零切断の任意の矢α:x→yで、完成局所環は `R_X[[u₁,…,u_g,v₁,…,v_g]]`、sourceの完成は `R_X[[u₁,…,u_g]]` の包含である。全Artin比較によりsource・targetは相対次元gで滑らかになる。可換零切断は全同値でschemeとして保存される。

非零方向のgraded同型は、低次数の完全対称化と交換子関係から重み付き線型になる。座標変換を取り除くと、残るパラメータ差は次数1でSym⁶K、次数2でSym⁴Kの中央係数だけである。この係数方向における中心元Ωの微分JΩは、方向解消の例外因子上で恒等となる。properな悪条件像を除いてJΩを可逆にし、小Artin拡大の中心差Δを `ξ=JΩ⁻¹Δ` で補正する。中央係数写像の大域的単射性は要求しない。

従って零切断Z全体を含む開Wで、**全ての矢を保った**群oidE_W⇒Wのsource・targetが相対次元gで滑らかになる。`U=[W/E_W]` は有限型で整なDMスタックで、全可換模型とその全Artin変形を含む。次数2・n≥3での非smooth locusは、点集合および被約閉部分として可換locusに一致し、Jacobianイデアルによる構造の一致は主張しない。

### 全モジュライ内の開性

局所Noether C-schemeのfppf site上で、**任意のM族の反標準軌道環が有限表示となり、任意の二つのM族の全O同値層がアフィン有限表示となる。** Serre周期を使って許容Z代数のNoether性を軌道環へ移し、相対Serre双対・有向ACMと豊富列から圏を復元する。構成族と任意M族との混合同値層に適用すると、U→Mは代数空間で表現可能な局所有限表示monomorphismとなる。上の全点Artin比較が形式的étale性を与え、**U→Mは開埋込み**となる。全Mの代数性は仮定しない。

任意M族の可換ファイバーの周囲には、このUに入る基底のZariski開近傍がある。完備Noether局所基底上の任意M対象も、閉ファイバーが可換なら、対応する構成族の実際の模型と同値になる。形式同値をアフィン有限表示の混合同値スキームで代数化する。形式的普遍性やlimit preservationだけから開性・effectivityを推論していない。

### 有限対角、粗モジュライ、可換模型

中心元Ωを完全対称化の逆で可換多項式へ移した `F^sh=Sym⁻¹Ω` は、零切断を保った縮小上で滑らかな可換del Pezzo族を定める。全O同値はこの可換模型の同型を誘導し、そのIsomへの閉埋込みを与える。古典モジュライの有限対角から、**Uの対角も有限**となる。従って分離的で整な有限型粗空間 `M^nc` が存在する。選んだ中心元と完全対称化に付随する可換模型は、全同値に対して関手的で、零切断では元の可換模型を返す。

各可換点Xでは、Γ=Aut(X)不変な実際の有限型affine slice Tを取り、`[T/Γ]→U` をrepresentable étaleかつstabilizer preservingにできる。粗空間の射 `T/Γ→M^nc` もétaleで、粗射との正方形はCartesianである。従って可換点の実際の粗空間の完備局所環は `R_X^Γ` となり、その点で粗空間は正規、Cohen–Macaulay、解析的に一分枝である。一般の可換XではΓ=μ₂がPoisson方向に符号で作用し、局所模型は古典係数空間と方向錐の2次Veronese商の積の開部分となる。この粗空間は可換点で特異である。

**Uの一般安定化群は自明**で、非零方向には稠密な滑らかな代数空間の開部分がある。可換点には被覆対合があるため、慣性の平坦性を零切断まで要求しない。次元は `dim U=dim M^nc=b(n,1)+n` または `b(n,2)+2n−1`。n=2,3,4でそれぞれ次数1は10,37,107、次数2は9,24,52である。全Uを一つの有限群商とは主張しない。

## Poisson shadowと相対幾何

`F^sh` はzについて偶であり、次数1では `ι_(dF^sh)(D∧∂y∧∂z)`、次数2では `ι_(dF^sh)(P∧∂z)` がその超曲面上のPoisson構造を与える。Jacobi恒等式と全graded同型に対する厳密な変換則を、冪零元を含む任意の可換基底で証明した。従ってshadowは **`Θ:U→P`** に持ち上がる。可換点の全framed完成でΘは同型となり、全零切断を保つ開縮小により、表現可能・分離的・有限表示・étaleかつ全点でstabilizer preservingとなる。Poisson零切断のscheme論的な逆像も可換零切断そのものである。

`sh:U→D` はschemeで表現可能なquasi-affine射で、平坦全射かつ有限表示である。幾何学的ファイバーは次数1でA^n、次数2でPlücker錐 `Cone Gr(2,n+1)` へのétale射を持ち、純次元はnまたは2n−1となる。全ファイバーは正規・Cohen–Macaulay・Gorensteinである。全ファイバーの既約性や、錐全体との同型は主張しない。次数1と次数2のn=2ではshは滑らか。次数2・n≥3では相対非smooth locusの台が可換零切断に一致し、n=3では5次元通常二重点、n≥4では局所完全交叉でない錐が現れる。

粗射 `M^nc→N` も分離的étaleで、スタックのΘと粗射の正方形はCartesianとなる。Poisson粗空間Nがaffineであることから、**M^ncは正規Cohen–Macaulayなquasi-affine scheme**となる。粗shadow `M^nc→M^cl` の平坦点は、**古典粗空間M^clの滑らかな点の逆像とちょうど一致する**。これはスタックshadowの全域的な平坦性とは異なる現象である。

次数2では可換零切断のblow-upがPoisson側のblow-upのétale基底変更となる。n≥3では滑らかなDMスタックによる解消で、例外因子はD上の相対 `Gr(2,n+1)`、その法束はtautological `O(−1)` である。Uはsmooth atlasの意味でGorensteinかつterminalで、discrepancyはnとなる。粗空間のGorenstein性・terminal性はここからは結論しない。

## 残る核心と確実性

最高活性部分の逆係数写像は、h=1の二係数族について、次数1ではPoisson側のy二次項を消す正規化後に次数5、次数2の対称binary quarticでは次数4である。次数2では全lowerを各top分枝に三角的に一意復元できる。さらに、規格化中心そのもののtorsor T=(P,U mod Sym⁴K,Ω) を作り、元の全方向族W→TのCasimir Jacobianからétale性を得る。全同値群oidの商は [O^sat/G₂] となり、元の中心パラメータの余分な多価性は消える。binary quarticの一般安定化群V₄とnormalizer商S₃、同じ全座標群によるCartesian商図式から、全モジュライの一般次数 δ_(n,2)=4 を得た。証明は主原稿 `sec:shadow-top-inverse` と `sec:degree-two-shadow-degree`。有限計算は自由語中心式・逆関係・S₃同変性・Lie軌道の行列式を厳密に検証する。次数1の係数次数5は、全Θの次数や下界とは同一視しない。

**次の核心は、次数1の全比較の次数、次数2の四枚の被覆の幾何、開部分Uの外の対象・成分である。** 次数2では一般点を含む開上で有限étaleな四枚の被覆となるが、可換点のファイバー長は1なので、可換点を含むZariski近傍で有限・properにはできない。可換点での完成同型と大域的な四価性は両立する。次は四分枝のモノドロミー・開像・境界を調べ、次数1ではlower復元とPoisson側のy平行移動の商を比較する。一般論の障害を示すμ₂同変な t↦t+t³ の反例も保持している。

全Mの被覆、可換locusに接しない成分、中心増大層での追加同値も調べる。特殊な可換模型について `R_X^Aut(X)` を計算し、粗空間の特異層を記述する。中心元・smoothness・Casimir Jacobian・Hochschild階数の追加開条件の最小明示式、全有限パラメータの境界分類、全成分数は残る。形式的普遍性だけでは有限型表示へ移れない一般群oidの反例も、追加の持上げ・有限表示条件が必要な理由として保持する。
